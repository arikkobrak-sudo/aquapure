# 💧 AquaPure • Естетичний трекер води

Затишний, преміальний та персональний трекер випитої води з живою фізикою рідини (Liquid Glass), ніжним інтерактивним компаньйоном та теплими сюрпризами.

Створено за сучасними трендами дизайну 2025–2026: **відмова від нав'язливого тиску**, швидке логування в один тап (< 2 секунд), кришталевий скляний неоморфізм та процедурні ASMR-звуки.

---

## ✨ Особливості та Фішки

1. **Жива колба (Liquid Glass Vessel)**:
   - Процедурна симуляція подвійної хвилі на HTML5 Canvas (60+ FPS).
   - Динамічний сплеск хвилі при наповненні та спливаючі мікробульбашки.
   - Кришталевий скляний корпус із відблисками, каустикою та неоновим ореолом.

2. **Ніжний компаньйон (Краплинка)**:
   - Плаває на поверхні води і слідує за її рівнем.
   - Моргає, посміхається, підстрибує від радості при кожному ковтку (`^‿^`).
   - Натискання на крапельку викликає милі цитати в хмаринці діалогу.
   - При досягненні 100% на ній з'являється сяюча корона!

3. **Швидке логування в 1 тап**:
   - `+150 мл` (Чашка ☕)
   - `+250 мл` (Склянка 🥛)
   - `+350 мл` (Горнятко 🫖)
   - `+500 мл` (Пляшка 💧)
   - Кнопка швидкого кастомного об'єму зі слайдером.
   - Миттєва кнопка **Скасувати (Undo)** при випадковому натисканні.

4. **ASMR Звуки води (Web Audio API)**:
   - М'яке булькання при додаванні порції.
   - Гармонійний кришталевий дзвін келиха при виконанні денної норми (100%).
   - Жодних важких аудіофайлів — все синтезується на льоту без затримок та працює офлайн.
   - Кнопка швидкого вимкнення звуку в один клік у шапці.

5. **Персональні романтичні секрети ❤️**:
   - **Мікро-вітання**: тепле сповіщення з компліментами на 50% норми та конфеті-салют на 100%.
   - **Секретна пасхалка (Easter Egg)**: довгий тап (1.5 сек) на скляну колбу (або клік на підказку внизу) запускає романтичне сяйво, плаваючі сердечка, звук биття серця та відкриває особисту записку.
   - Текст записки та ім'я дівчини можна легко змінювати в налаштуваннях!

6. **Кольорові теми води**:
   - **Aqua Crystal** (кришталевий гірський лазур)
   - **Mint Breeze** (освіжаюча лагуна)
   - **Rose Sunset** (ніжний персиково-рожевий)
   - **Moonlight Dream** (зоряна лавандова ніч)

7. **Повна автономність (PWA & Offline)**:
   - Працює офлайн через Service Worker.
   - Усі дані зберігаються виключно локально (`localStorage`) — 100% приватність, без реєстрацій та серверів.
   - Легко встановлюється на головний екран iPhone (Safari -> «На екран "Додому"») та Android як рідний додаток.

## 🚀 Запуск проєкту локально

```bash
# Встановити залежності (якщо потрібно)
npm install

# Запустити локальний сервер розробки
npm run dev
```

Відкрийте в браузері: `http://localhost:5173/`

## 📱 Як задеплоїти (щоб вона могла відкрити на телефоні)

1. Завантажте цей репозиторій на GitHub.
2. Перейдіть на [Vercel](https://vercel.com) або [Netlify](https://netlify.com) і натисніть **Add New Project**.
3. Виберіть репозиторій — Vercel автоматично виконає збірку (`npm run build`) за 10 секунд і видасть гарне посилання виду `https://aquapure-hername.vercel.app`.
4. Надішліть їй посилання, відкрийте в Safari на iPhone і натисніть:
   **«Поділитися» (Share) ➔ «На екран "Додому"» (Add to Home Screen)**.
   Додаток отримає стильну іконку та відкриватиметься на повний екран без панелей браузера!
